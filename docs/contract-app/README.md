# 계약서 자동작성 앱 ↔ 캠페인 허브 연결

계약서 앱은 **새 탭으로 연다**(허브 화면 안에 넣지 않는다). 계약서 앱은 서류 뷰어와 입력 칸이 나란히 있는 넓은 화면이고, 각자 PC에서만 돌아야 개인정보 원칙이 지켜지기 때문이다.

캠페인 허브에서 크리에이터의 **계약서 작성** 링크를 누르면 계약서 앱이 새 탭으로 열리고, 아래 네 칸이 미리 채워집니다.

| 계약서 앱 칸 | 캠페인 허브 값 |
|---|---|
| 계약 정보 → 캠페인명 | 캠페인 이름 |
| 계약 정보 → 광고주명 | 광고주 |
| 계약 정보 → 업로드 날짜 (광고기간·발행일·지급조건이 이 날짜로 자동 계산) | 캠페인 업로드 날짜 |
| 광고 금액 → 첫 라인 크리에이터명 | 크리에이터 이름 |

## 개인정보는 어떻게 되나

- 계약서 앱은 지금처럼 **각자 PC에서만**(`localhost:8501`) 열립니다. 설정(`.streamlit/config.toml`의 `address = "localhost"`)은 바꾸지 않습니다.
- 허브 → 앱으로는 위 네 가지 값만 주소에 담겨 넘어갑니다. 앱 → 허브로는 아무것도 넘어가지 않습니다.
- 서류(신분증, 통장 사본, 사업자등록증)와 읽어 온 값은 지금처럼 PC 밖으로 나가지 않습니다.

## 계약서 앱에 넣을 수정 (app.py 두 곳)

수정 전에도 링크는 동작합니다. 앱이 그냥 빈 상태로 열릴 뿐입니다. 미리 채우려면 아래를 넣습니다.

1. [hub_prefill.py](hub_prefill.py)의 `apply_hub_prefill()` 함수를 `app.py`에 붙여 넣습니다.
   `info_key`, `UPLOAD_DATE_KEY`, `ppl_key`가 정의된 뒤면 어디든 됩니다(예: "광고 금액" 절의 `ppl_key` 함수 아래).
2. `main()` 맨 앞을 이렇게 바꿉니다.

   ```python
   def main() -> None:
       apply_queued_values()  # 위젯을 그리기 전에 반영해야 한다
       apply_hub_prefill()    # 캠페인 허브에서 연 경우 캠페인 정보 미리 채우기
       render_sidebar()
   ```

새 패키지나 인터넷 연결은 필요 없습니다(`st.query_params`는 지금 쓰는 Streamlit에 들어 있습니다). 수정한 `app.py`로 배포 폴더를 다시 만들면 됩니다.

## 동작 규칙

- 주소에 `from=campaign-hub`가 있을 때만 채웁니다. 다른 경로로 연 앱은 지금과 똑같습니다.
- 칸을 그리기 전에 한 번 넣고, 바로 주소의 값을 지웁니다. 그래서 사용자가 고친 값을 덮지 않고, **모두 지우기** 뒤에도 다시 채워지지 않습니다.
- 업로드 날짜 형식이 맞지 않으면 기본값(오늘)을 둡니다.

## 확인한 것

계약서 앱과 같은 칸 이름(`ci_campaign`, `ci_advertiser`, `ci_upload_date`, `ppl_0_creator`)과 같은 순서로 그린 작은 Streamlit 앱에 이 함수를 넣어 Streamlit 1.67 `AppTest`로 확인했습니다.

- 허브 링크로 열면 네 칸이 채워진다
- 채운 뒤 사용자가 고친 값이 다시 그려도 유지된다
- 모두 지우기 뒤에 다시 채워지지 않는다
- 허브가 아닌 주소와 잘못된 날짜는 무시한다

### 실제 계약서 앱 v3.1에서 (2026-11-09)

팀에서 쓰는 계약서 앱 v3.1 배포본을 PC에 풀고, `app.py`에 위 두 곳을 넣은 뒤 실행 파일로 띄웠습니다(첫 설치 약 7분). 캠페인 허브의 글로우핏 캠페인에서 데일리민지의 **계약서 작성**을 누르자 새 탭의 계약서 앱에 아래 값이 채워졌습니다.

| 칸 | 값 |
|---|---|
| 캠페인명 | 글로우핏 수분 선크림 |
| 광고주명 | 뷰티랩 |
| 업로드 날짜 | 2026.12.03 |
| 광고 금액 첫 라인 크리에이터명 | 데일리민지 |
| (자동 계산) 광고기간 · 세금계산서 발행일 · 지급조건 | 2026.12.03 ~ 2026.12.03 · 2026.12.31 · 2027.01.30(세금계산서 발행 기준 30일 이내) |

열린 뒤 주소창의 값은 지워져 `http://localhost:8501/`만 남습니다.

배포본에 넣은 뒤에는 앱 저장소의 `tests/test_app_reset.py`와 단위 테스트를 한 번 돌려 주세요(배포 zip에는 `tests/`가 없어서 돌리지 못했습니다).
